# Resumen-aplicaciones-movil
Resumenes clases aplicaciones movil

Este proyecto representa la culminación de un proceso de diseño holístico de 20 sesiones, donde se ha abordado la creación de una aplicación móvil no solo como una interfaz visual, sino como un sistema vivo que integra estrategia de negocio, psicología del usuario y tecnología avanzada.


Fase 1: Empatía y Estructura (Investigación y Arquitectura)
El desarrollo comenzó con una fase de investigación profunda, alejándonos de las suposiciones para centrarnos en hechos mediante el "Mom Test" y el marco de trabajo "Jobs-to-be-done". A través del análisis del panal de 7 facetas de Morville, definimos una propuesta de valor centrada en la utilidad y la credibilidad. La estructura de la información se validó mediante Card Sorting, aplicando la Ley de Miller y patrones de navegación móviles para garantizar que el usuario nunca pierda el control en un entorno de uso hostil (interrupciones, luz solar y uso con una sola mano).


Fase 2: Identidad y Sistema Visual (Diseño de Interfaz)
Para garantizar la escalabilidad, se construyó un Sistema de Diseño (Design System) basado en Atomic Design y el uso de Design Tokens. La jerarquía visual se rigió por las Leyes de UX (Fitts, Hick y Jakob) y las 10 Heurísticas de Nielsen, asegurando que cada pantalla pueda entenderse en menos de 3 segundos. El diseño se complementó con microinteracciones con propósito y un enfoque en el diseño emocional, buscando no solo la funcionalidad, sino el deleite del usuario a través de un feedback "juicy" y mecánicas de gamificación ética.


Fase 3: Adaptabilidad y Humanización (Plataformas y Contenido)
Reconociendo la diversidad del ecosistema móvil, el proyecto integra convenciones nativas tanto de iOS (HIG) como de Android (Material 3). La inclusión fue un pilar fundamental, aplicando los principios POUR de accesibilidad (WCAG) para asegurar que la app sea operable por personas con diversas capacidades. Asimismo, se desarrolló una estrategia de onboarding progresivo y un microcopy de tono humano, eliminando fricciones y guiando al usuario hacia su primer "momento Aha".


Fase 4: Validación, Futuro y Negocio (Métricas, IA y Lanzamiento)
Finalmente, el producto fue sometido a pruebas de usabilidad iterativas (método RITE) para corregir errores críticos antes de su implementación. El modelo de negocio se diseñó bajo una mirada de Service Design, alineando la monetización con la transparencia. Como elemento innovador, se integró un asistente de Inteligencia Artificial diseñado como un "copiloto", priorizando la explicabilidad y el control humano.


El resultado es una aplicación validada, accesible y lista para el mercado, medida bajo el marco HEART de Google para garantizar un éxito sostenible basado en la retención y la felicidad real del usuario.
